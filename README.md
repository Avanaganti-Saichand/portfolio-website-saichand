# Saichand Avanaganti — Portfolio

Minimal, typography-first personal site. White background, one column, no animation libraries — content is the interface.

- **Next.js 14** (App Router, fully static) + TypeScript + Tailwind CSS
- All content in [`data/resume.ts`](data/resume.ts) — edit one file to update the site
- Self-hosted fonts (Inter, JetBrains Mono)

```bash
npm install
npm run dev
```

Deploys anywhere Next.js runs; optimized for Vercel.
