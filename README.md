# Saichand Avanaganti — Portfolio

Premium product-style personal brand site for a senior mobile / full-stack / AI engineer.

## Highlights
- **Profile modes** — Recruiter / Engineer / Product switch reframes every case study
- Hero with live product-console mockup (mobile, AI pipeline, API status, delivery metrics)
- Bento-grid featured case studies with animated gradient border
- Engineering Impact metrics, animated experience timeline, categorized skill cards, tech marquee
- Cursor spotlight, scroll reveals, hover lifts — all reduced-motion aware
- Accessible: semantic sections, focus-visible states, keyboard navigable, high contrast

## Stack
Next.js 14 (App Router) · TypeScript · Tailwind CSS · Framer Motion — no heavy 3D assets.
All content lives in [`data/resume.ts`](data/resume.ts).

```bash
npm install
npm run dev
```
